# 🐾 MyLittlePet - Gamified Virtual Pet App

![MyLittlePet Banner](https://via.placeholder.com/800x300.png?text=MyLittlePet+-+Gamified+Virtual+Pet)

**MyLittlePet**, React Native ve Expo ile geliştirilmiş, modern UI/UX prensiplerini ve oyunlaştırma (gamification) mekaniklerini temel alan interaktif bir sanal bebek uygulamasıdır. Klasik "Tamagotchi" deneyimini modern bir görsellik ve ödül sistemiyle birleştirir.

---

## 🚀 Projenin Amacı ve Oyunlaştırma Özellikleri

Bu projenin amacı, kullanıcının sanal bir canlı ile duygusal bağ kurmasını sağlarken, çeşitli mikro-görevler ve ödül mekanizmalarıyla etkileşimi süreklileştirmektir.

### 🎮 Oyunlaştırma Unsurları:
- **🏆 Başarım (Achievement) Sistemi:** Özel dönüm noktalarında açılan, manuel olarak ödülleri toplanabilen başarımlar.
- **⭐ XP ve Seviye Sistemi:** Petinizle ilgilendikçe XP kazanırsınız. XP arttıkça petiniz seviye atlar.
- **🪙 Ekonomi (Altın & Mağaza):** Görevlerden ve oyunlardan kazanılan altınlarla petin görünümünü ve odasını özelleştirebilirsiniz.
- **📋 Günlük Görevler:** Her gün otomatik olarak yenilenen, dinamik görev listesi.
- **🎲 Rastgele Olaylar:** Petin hastalanması, hediye bulması gibi anlık gelişen olaylarla dinamik oyun yapısı.
- **🏮 İnteraktif Uyku Döndüsü:** Lamba kontrolüyle petin uyuma süreci bizzat yönetilir.

## 🛠️ Kurulum ve Çalıştırma Talimatları (Installation & Run)

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

### Gereksinimler:
- Node.js (LTS sürümü tavsiye edilir)
- Expo Go uygulaması (Mobil cihazınızda)

### Adımlar:
1. **Depoyu klonlayın:**
   ```bash
   git clone https://github.com/mlkaydemir/modum.git
   cd modum
   ```

2. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

3. **Uygulamayı başlatın:**
   ```bash
   npx expo start
   ```

4. **Cihazda Çalıştırın:**
   - Terminalde çıkan **QR kodu**, mobil cihazınızdaki **Expo Go** uygulamasıyla taratın.
